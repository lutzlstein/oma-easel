# Logo

`logo-source.png` was generated with Codex's built-in image tool from:

> logo for Easel, an omarchy background generator. A painter's easel (wooden easel with a small blank-ish canvas on it) shown on the screen of a 1980s single-body terminal computer: one boxy beige all-in-one CRT unit with the screen built into the body, no separate keyboard. The easel is drawn inside the glowing screen. Flat vector logo style, bold near-black outlines of even weight, a few flat colors, no gradients on the outline, no text, no letters. Square image with a transparent background.

`src/assets/logo.png` is that image trimmed to its content and scaled to 512px. It carries its own contrast (beige body, dark outline), so it is shown in full color on every theme. The window shows the app's name as text beside it, so renaming the app needs no new image.
